# ⛏️ Infinite Mine Tycoon

A mobile-friendly 2D mining tycoon game. Tap to dig, sell ore, buy machines, and keep going deeper.

## Play in a browser
Open `app/src/main/assets/index.html` locally in a browser. Progress is saved in local storage.

## Build Android APK
1. Open the **Actions** tab in this repository.
2. Select **Build Infinite Mine APK**.
3. Press **Run workflow** (or push a code change to `main`).
4. When it finishes, open the run and download the `infinite-mine-tycoon-debug-apk` artifact.

The APK is a debug build for testing, not a Play Store release.
